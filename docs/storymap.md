# storymapのストーリーマップ

ユーザーは「Rust開発者」。\
自分のアプリやツールで、Markdownのアウトラインからストーリーマップを描きたい。\
「他言語の開発者」は、このクレートを包んだバインディング（WebAssemblyなど）を通して使う。

1. アクティビティ
2. タスク
3. ウォーキングスケルトン
4. ライブラリとして一通り使える
5. ほかの形式で出力する

- 準備する #Rust開発者
  - クレートを導入する
    - [x] Gitのタグを指定して依存に追加する
      - [x] HTMLが要らなければ、html featureを外す
- アウトラインを読む #Rust開発者
  - 項目を配置する
    - [x] アクティビティとタスクを、インデントの深さでレベルと列に配置する
      - [x] チェックボックスで、完了と未完了を読む
        - [x] ^ 末尾のハッシュタグを、タグとして読む
  - スライスを決める
    - [x] v 「^」と「v」のマーカーで、スライスを自由に決める
      - [x] ^ 順序付きリストを、レベルのタイトルとして読む
  - 文書の中から読む
    - [x] v 「Story Map」見出しの節だけを、アウトラインとして読む
      - [x] ^ 「//」で始まる項目を、メモとしてカードにしない
        - [x] ^ アウトラインの上下の段落を、ノートとして読む
          - [x] ^ 最初の見出しを、タイトルとして読む
- マップを描く #Rust開発者 #他言語の開発者
  - 自分のUIで描く
    - [x] 配置済みのデータ（StoryMap）を受け取る
  - HTMLで描く
    - [x] HTMLとCSSを受け取る
      - [x] インラインのMarkdownを、HTMLにする
  - 画像で描く
    - [x] vv マップをSVGとPNGで出力する
