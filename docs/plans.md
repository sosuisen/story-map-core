## マップをSVGとPNGで出力する

- 仕様（ユーザーと合意済み）
  - `image` featureを足す（既定では無効）。文字の幅の計測とPNGへの描画は、resvgに任せる
  - `image::render_svg(&map, &ImageOptions) -> String` と `image::render_png(&map, &ImageOptions)`
  - `ImageOptions`はフォント（`fontdb::Database`）と倍率を持つ。既定ではOSのフォントを読む
  - 見た目はHTML版のCSSに合わせる。1枚のカードは1行で、折り返さない
  - 太字・斜体・コードは書体で表し、リンクはただの文字にする
- テストリスト
  - [ ] SVGは、マップ全体が入る大きさのSVG文書になる
  - [ ] カードの文字が、SVGの文字として描かれる
  - [ ] アクティビティは左から右へ、アウトラインの順に並ぶ
  - [ ] 子のカードは、親の下に同じ列で並ぶ
  - [ ] 長い文字のカードの列は、短い文字の列より広くなる
  - [ ] 短い文字のカードも、最小の幅（120px）を持つ
  - [ ] 同じ列のカードは、同じ幅になる
  - [ ] カードと帯は、レベルの色で塗られる
  - [ ] レベル4より下の帯は、1つおきに少し明るくなる
  - [ ] 完了のカードは枠線がなく、未完了のカードには影がある
  - [ ] チェックボックスは、絵文字として描かれる
  - [ ] タグは、本文の後ろに丸い背景付きで描かれる
  - [ ] レベルのタイトルは1列目に描かれ、カードは2列目から始まる
  - [ ] `^`で同じレベルに入ったカードは、帯の2行目に描かれる
  - [ ] カードのないレベルは、細い帯として描かれる
  - [ ] タイトルとリストの上のノートは、マップの上に描かれる
  - [ ] リストの下のノートは、マップの下に描かれる
  - [ ] 太字・斜体・コードは、書体を変えて描かれる
  - [ ] XMLの特殊文字は、エスケープされる
  - [ ] PNGは、SVGと同じ大きさに倍率を掛けた画像になる
